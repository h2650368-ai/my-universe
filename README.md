# MY UNIVERSE

A mobile-first, iPhone-inspired personal space published with GitHub Pages.

## Included
- Arabic and English interface with RTL/LTR switching.
- Personal sections for ideas, writing, photos and memories, goals, and projects.
- Search across saved text and goals.
- Local notes and goals storage, photo storage in IndexedDB.
- JSON export/import for notes, writing, projects, and goals.
- Personal AI chat prototype UI (not connected to an AI model).
- PWA manifest, app icon, service worker, and offline app-shell caching.
- Responsive layout and safe-area support for mobile devices.

## Publish
In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
The site URL is https://h2650368-ai.github.io/my-universe/.

## Install
- Android: open the site in a supported browser and choose Install app or Add to Home screen.
- iPhone: open in Safari > Share > Add to Home Screen.

## Privacy and limitations
This is a static front-end app. User content is stored in the browser on the current device; it is not synced to a cloud account and is not protected by a real sign-in system. Clearing browser data may remove locally stored content. Export backups regularly.
The Personal AI section is a prototype only. A real AI integration must use a secure server-side backend; never put secret API keys in this public repository.
